## 9. NVIDIA Brev 클라우드 배포

### 9.1. 필수 포트

| 포트 | 프로토콜 | 용도 |
|------|----------|------|
| 49100 | TCP | WebRTC 시그널링 |
| 47998 | UDP | WebRTC 미디어 스트림 |
| 8210 | TCP | 웹 뷰어 (Docker Compose) |

### 9.2. 컨테이너 실행 명령어

```bash
# Brev 인스턴스에서 실행
PUBLIC_IP=$(curl -s ifconfig.me)
mkdir -p ~/docker/isaac-sim/{cache/main,cache/computecache,cache/kit,config,data,logs,pkg}
sudo chown -R 1234:1234 ~/docker

ISAACSIM_HOST=$PUBLIC_IP ISAAC_SIM_IMAGE=nvcr.io/nvidia/isaac-sim:6.1.0 \
    docker compose -p isim -f tools/docker/docker-compose.yml up --build -d
```

### 9.3. 연결

- 웹 뷰어: `http://<PUBLIC_IP>:8210`
- WebRTC 클라이언트: Isaac Sim WebRTC Streaming Client 앱 사용
